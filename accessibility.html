Accessibility

Version 1.0 · Last updated October 26, 2026

We want everyone to be able to use this site. It was built with accessibility in mind, aiming for the Web Content Accessibility Guidelines (WCAG) 2.1 level AA.

What we did

  • Services, the phone number, hours and the service area are real text on the page, not pictures or PDFs.
  • Everything works with a keyboard, with a visible focus outline and a “Skip to content” link.
  • Text and buttons meet color-contrast guidelines, and the page works when zoomed to 200%.
  • Photos have text descriptions, and animations turn off if your device asks for reduced motion.
  • Each page was checked with the automated axe accessibility tool and by hand with a keyboard.

Known limits

Automated tools catch only some problems, and we may have missed something. Links to Google and Yelp open those sites, which we don’t control.

Need help or found a problem?

Call or text (330) 262-1543, or report a website issue and we’ll fix it.
